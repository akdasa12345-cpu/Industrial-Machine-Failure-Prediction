# PBL 2: Industrial Machine Failure Prediction
**Section:** C | **Level:** MCA

## Overview
This project predicts whether an industrial machine may fail using operating measurements such as air temperature, process temperature, rotational speed, torque, tool wear, and machine type.

## Project structure
- `data/ai4i_demo_sample.csv` — illustrative synthetic sample data.
- `src/train.py` — data preparation, three classifiers, evaluation, cross-validation, tuning, and model saving.
- `src/predict.py` — example prediction for unseen machine measurements.
- `report/Project_Report.md` — project documentation.
- `requirements.txt` — dependencies.

## Dataset note
The included CSV is **synthetic demonstration data**, not the official AI4I 2020 dataset. For the final study, download the official AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository and save it as `data/ai4i2020.csv`. The training script automatically uses that file when present; otherwise it uses the demo sample.

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/train.py
python src/predict.py
```

The script creates `artifacts/` after execution. Metrics and best parameters are generated by running the experiment; no results are fabricated in this package.
